FAQ

Good to know

Short answers to the questions that come up before a first batch.

Are my photos uploaded anywhere?

No. The browser reads the files locally and draws them on a canvas. Only the page itself is downloaded from the web.

What does “never enlarge” do?

If a photo is already smaller than the target size, it stays at its original size instead of becoming blurry. Turn it off if you need every file to have exactly the same dimensions.

Can I use a logo instead of text?

This version watermarks with text. A PNG logo upload is the next feature on the list.

How many photos can I process at once?

There is no fixed limit, but very large batches (100+ high-resolution photos) need more memory. Process them in groups of 30–50 for smooth results.
